# 🚀 SwiftQuest

> **Swift & SwiftUI. Depth, in an age of shortcuts.**

Welcome to the official repository for **swiftQuest**—an educational initiative focused on first-principles Swift and SwiftUI engineering. 

Rather than superficial snippets, this repository contains structured Xcode Playgrounds, starter code, and completed exercises designed to understand the basics of SwiftUI. This will be our launch pad for more production-grade series coming later.

## 🛠️ How to Use This Repository

1. **Download the Assets:** Grab the Xcode Playground `.zip` file for the corresponding module from the table above.
2. **Follow Along:** Open the playground to access both the starter code and completed reference exercises as you watch the video lessons.
3. **Get the Bundles:** Download additional cheat sheets and key takeaways via the Resource Bundle links.
